# Privacy

This extension does not use analytics, telemetry, advertising, or third-party services.

The extension stores only the selected evaluation score in Chrome local extension storage under `slcmEvaluatorScore`.

The extension runs only on the SLCM survey pages listed in `manifest.json`. When it submits a form, the form data is sent to the original SLCM website in the same way a manual submission would be sent. No data is sent to this project or to any external service.

Do not publish captured HTML pages, PDFs, screenshots, notes, credentials, cookies, or any student/patient/institutional data with this repository.
