# Security Policy

## Supported Versions

Only the latest version on the default branch is supported.

## Reporting a Vulnerability

Please report vulnerabilities privately to the maintainer when possible. If no private contact is available, open a public issue with a high-level description only and omit exploit details, credentials, screenshots, or institutional data.

## Permission Changes

Any pull request that expands Chrome permissions must explain why the new access is required and why a narrower permission is not enough.
